## Product and entry point

The independent loopback Model Trust Inspector serves an ML engineer inspecting one or two authorized files. Actual static engines read supplied bytes and report hashes, structures, offsets and findings; the browser compares results and exports a report/checksum bundle. Bounded supported inputs are raw pickle, SafeTensors, GGUF metadata/descriptors and Python source. A complete inspection is not proof of safety, behavior, origin, publisher identity or training lineage. The inspector never loads a model.

On supported Linux/Python3.10+ with libseccomp, create a venv, install requirements-local.lock, install this project with --no-deps -e ., then run python -m scanner.workbench.server and open http://127.0.0.1:8763. README.md and docs/WORKBENCH.md contain exact commands, selection/inspection/evidence/comparison/export flow, limits, errors and recovery. No provider key or paid service is needed. Installed distributions truthfully report source UNKNOWN. This is a trusted single-operator local app, not authenticated internet hosting. Input bytes are not extracted or persisted by the backend; original files/explicit downloads remain on the operator's disk. Memory reclamation is not cryptographic erasure.
